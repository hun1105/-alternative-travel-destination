## 2. 화면 구조 및 UI 레이아웃

Plan B는 여행자가 한 화면에서 지도, 일정, 돌발상황을 직관적으로 조작할 수 있도록 3패널 반응형 레이아웃을 채택하였습니다.

```text
+----------------------------------------------------------------------------------------------------+
|                                    Plan B 반응형 3패널 레이아웃                                     |
+------------------------------+------------------------------------+--------------------------------+
|  [좌측] 여행 정보 & 시나리오    |     [중앙] 인터랙티브 지도 뷰      |    [우측] 일정 & 경로 상세     |
+------------------------------+------------------------------------+--------------------------------+
| • ⚡ 심사용 원터치 시나리오  | • [◀ 접기] 버튼                    | • [⚡ 동선 최적화] 원클릭 버튼  |
| • 여행 기본정보(일자, 시간)  | • 일정 순번 번호 핀 (1, 2, 3...)   | • 일정 목록 (체류, 고정시간)   |
| • 6대 추천 선호도 칩         | • 구간별 교통수단 폴리라인         | • [🔒 잠금] 체크박스           |
| • 키워드 장소 검색창         | • 지하철 호선 색상 / 버스 노선 라벨| • [이 일정 빼고 대체추천] 버튼 |
|                              | • [접기 ▶] 버튼                    | • 3대 복구 대안 카드 패널      |
+------------------------------+------------------------------------+--------------------------------+
```

## 3. 6대 핵심 기능 상세 명세

### 3.1 [기능 1] 당일 일정 설계 및 장소 검색
* **동작 원리:** 한국관광공사 TourAPI `searchKeyword2`를 통해 전국 관광지를 실시간 검색하고 클릭 한 번으로 일정에 등록합니다.
* **관광 정보 매칭:** 관광타입(관광지 12, 문화시설 14, 축제공연 15, 레포츠 28, 숙박 32, 쇼핑 38, 음식점 39)을 자동 식별하여 배지를 부착합니다.

### 3.2 [기능 2] 중요 고정 일정 잠금(Lock) 보호
* **동작 원리:** 기차 출발 시각, 식당 예약 시간, 공연 관람 시간 등 절대 바꿀 수 없는 항목을 '고정 도착시각'과 '잠금'으로 설정합니다.
* **보호 효과:** 돌발 변수가 생겨 대안을 찾거나 동선을 최적화할 때, 잠긴 장소는 절대 순서가 바뀌거나 삭제되지 않고 제자리에 고정됩니다.

### 3.3 [기능 3] 실시간 돌발변수 감지 & 다기준 점수화 추천
* **돌발 변수:** 기상청 단기예보(강수, 폭염, 한파)와 서울시 실시간 인구혼잡도를 자동 수집합니다.
* **추천 알고리즘:**
  $$\text{Final Score} = \sum_{i=1}^{6} (w_i \times \text{Score}_i) - \text{Penalties}$$
  - **하드 필터:** 영업 종료, 정기 휴무, 다음 예약 도착 불가능, 우천 시 야외 명소를 1차로 완전 탈락 처리.
  - **소프트 스코어링:** 날씨 적합도, 이동시간 단축도, 혼잡 회피도, 아동 적합성, 보행 부담, 예산 적합도를 100점 만점으로 평가.
  - **위험 감점:** 여유시간 부족(-10점), 운영시간 불명확(-12점) 감점.

### 3.4 [기능 4] 3대 복구 대안 카드 (3-Tier Replacement)
* **🏆 종합 최적 (Best Alternative):** 원래 가려던 장소의 카테고리(문화/역사 등)를 가장 잘 계승하며 시간과 비용이 조화로운 대안.
* **🚶 최단 이동 (Minimum Transit):** 현재 위치에서 가장 가깝고 이동시간이 가장 짧아 체력을 보존하는 대안.
* **💰 최저 비용 (Lowest Cost):** 입장료가 무료이거나 가장 저렴한 공공 시설 중심 대안.
* **원터치 교체:** [이 후보로 교체] 클릭 시 3초 만에 타임라인, 이동 경로, 지도 마커가 한 번에 갱신됩니다.

### 3.5 [기능 5] ⚡ 원클릭 TSP 동선 최적화 (2026 최신 탑재)
* **배경:** 사용자가 장소를 이것저것 추가하다 보면 동선이 서쪽-동쪽-서쪽으로 심하게 꼬이는 현상(Zigzag Problem)이 발생합니다.
* **엔진 기술:** 외판원 순회(TSP) 알고리즘을 자체 구현하여, 8개 이하는 완전 탐색(Brute-force)으로 수학적 전역 최적해를 보장하고, 초과 시 2-Opt 휴리스틱으로 고속 수렴합니다.
* **제약 준수:** 출발지(1번 장소)와 잠금(Lock) 항목은 제자리에 고정하고 미잠금 항목만 최단 경로로 재배치합니다.
* **시연 검증:** 4개 지점(경복궁-올림픽공원-창덕궁-뚝섬) 꼬인 동선에서 **21.1km (약 51분) 단축** 효과를 즉각 입증하였습니다.

### 3.6 [기능 6] 복합 경로 안내 및 사이드바 토글 (전체화면 지도)
* **대중교통 시각화:** 지하철 1~9호선 고유 색상(2호선 녹색, 3호선 주황색 등) 폴리라인 및 버스 번호 마커 표출. 500m 이내 초근거리는 도보 경로로 자동 지능형 전환.
* **사이드바 토글:** 지도 상단 `◀ 접기` 및 `접기 ▶` 버튼으로 복잡한 패널을 접어 시원한 전체화면 지도로 경로를 조망할 수 있습니다.

## 4. 심사위원용 3초 원터치 시연 가이드

심사위원이 복잡한 입력 없이 3초 만에 본 서비스의 완결성을 체감할 수 있도록 데모 프리셋을 전면 배치하였습니다.

### [시연 1] 경복궁 폭우 대체 (기상 위험 극복)
1. 화면 좌측 상단의 **`[🌧️ 경복궁 폭우 대체]`** 버튼 클릭.
2. 경복궁(야외) 일정에 비가 내리는 상황이 시뮬레이션되며, 13:00 토속촌 삼계탕(식당 예약 고정) 시간을 지키는 3대 실내 대안 즉각 표출:
   - **종합 최적:** 대한민국역사박물관 (실내 박물관 / 도보 4분 / 무료)
   - **최단 이동:** 국립고궁박물관 (실내 전시 / 도보 2분)
   - **최저 비용:** 세종이야기 지하전시관 (실내 무료 / 도보 4분)
3. `[이 후보로 교체]` 버튼을 누르면 1초 만에 일정이 갱신되고 새 보행 경로가 지도에 그려집니다.

### [시연 2] 가족 동반 피로 복구 (아동/체력 한계 극복)
1. 화면 좌측 상단의 **`[👶 가족 피로 복구]`** 버튼 클릭.
2. 어린이가 지쳐 긴 도보가 불가능한 상황에서, 보행 300m 이내의 실내 키즈/문화 시설로 즉시 대체 추천되는 흐름 확인.

### [시연 3] ⚡ 원클릭 동선 최적화 (이동시간 절약)
1. 일정 목록에서 장소들의 순서가 꼬여 있을 때, 우측 상단의 **`[⚡ 동선 최적화]`** 버튼 클릭.
2. 하단에 `"⚡ 동선 최적화 완료! 이동거리 21.1km (약 51분) 단축"` 토스트 팝업이 뜨며, 지도 위 마커 번호와 타임라인이 서쪽에서 동쪽으로 일직선 최단 순서로 재정렬되는 모습 확인.

### [시연 4] 지도 전체화면 모드 (양방향 사이드바 토글)
1. 지도 좌상단 `◀ 접기` 클릭 $\rightarrow$ 좌측 여행 정보 사이드바 접힘.
2. 지도 우상단 `접기 ▶` 클릭 $\rightarrow$ 우측 일정 패널 접힘.
3. 지도가 전체화면으로 넓어지며 이동 경로와 대중교통 노선이 쾌적하게 조망됨 확인.
